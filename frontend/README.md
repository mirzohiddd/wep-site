# Halila — Frontend (Dizayn A: "Tabiiy / Hikoyaviy")

"Ishtaha yo'qolishi" (umumiy saraton) segmenti uchun asosiy, birinchi variant.
Issiq-yashil gradient hero, vertikal bo'lim tuzilishi, split lead-forma.

Backend bitta — barcha frontendlar bilan bir xil `backend/` papkasidan foydalanadi.

## Ishga tushirish

```bash
cd frontend
cp .env.example .env
npm install
npm run dev     # http://localhost:5173
```
